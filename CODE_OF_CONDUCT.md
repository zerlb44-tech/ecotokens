# Code of Conduct

Ecotokens contributors must participate in a professional, respectful, and constructive manner.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disclosure of private information, credential exposure, and disruption of project collaboration.

Maintainers may remove content or restrict participation when needed to protect contributors and the project. Report conduct concerns privately through the same security contact method documented in `SECURITY.md`; do not include sensitive personal information in a public issue.

This policy applies to project repositories, issue trackers, review discussions, and project-related public communication.
